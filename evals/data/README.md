# Evaluation data

- `hf_resume_job_fit_sample.json` — 24 PII-redacted pairs sampled from the **test** split of [`cnamuangtoun/resume-job-description-fit`](https://huggingface.co/datasets/cnamuangtoun/resume-job-description-fit) (8 Good Fit / 8 Potential Fit / 8 No Fit).
- Download more: `resume-checker download-dataset --limit 150`

Do not treat these texts as production candidate PII. They are public research samples used only for ranking/regression tests.
